# Personal Portfolio

My personal portfolio site, live at [josephmelesse.netlify.app](https://josephmelesse.netlify.app).

Terminal-themed (gruvbox), with my projects, an about page, and contact links. Project content lives in `client/src/data/projects.ts`.

## Stack

React 19, TypeScript, Vite, Tailwind CSS 4. Deployed on Netlify.

## Running it locally

```bash
cd client
npm install
npm run dev
```

Node 20+ is required (Vite won't start on anything older).
